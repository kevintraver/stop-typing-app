Sharper prose detection, an Advanced group for tuning it, and a Try It tab to watch it work.

## What changed

- **Try It.** Settings → Try It is a text box with a live readout of what the detector sees: how long the burst is, its word breaks and letter share, whether it reads as prose yet and why not, and which nudge comes next. It's the real detector, so the nudge really appears.
- **Advanced detection settings.** Settings → Detection → Advanced exposes the letter share, word breaks per character, the short-burst pause, the sustained-typing threshold and how often firm nudges repeat. Restore Defaults covers them too.
- **Vim motions stay ignored.** A burst now needs a word break at least every 12 characters, not just two anywhere, so navigation keys with the odd ⏎ or space no longer count as prose. Ordinary prose has one every 5 to 8.
- **Symbol keys count against prose.** `=` `+` `|` `<` `>` `$` `^` `~` and the backtick now count like punctuation instead of being skipped, so code is a little less likely to read as prose.
- **Detection settings carry over.** Settings saved by 1.0.4 keep every value as new ones are added.

Nothing you type is stored, logged or sent, and automatic update checks stay off unless you turn them on.
